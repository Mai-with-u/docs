# 关于本项目

MaiBot（麦麦）是一个基于大语言模型的可交互智能体。她试着了解你，用接近真人的方式跟你相处。

## 能力

- **自然对话** — 有长有短的闲谈，而不是一次吐出一大段。
- **参与群聊** — 读气氛，该开口时开口，该沉默时沉默。
- **模仿与学习** — 在多人聊天里模仿群友的说话风格，自己琢磨新词和圈子里的黑话。
- **长期了解你** — 基于心理学人格理论积累你的信息、喜好和说话风格。
- **插件系统** — 开放的 API 与事件系统，扩展空间没有上限。

## 设计理念

> **千石可乐说：**
>
> 这个项目最初只是想给牛牛 bot 加点小功能，结果越写越多，最后干脆重写了。目标是在 QQ 群聊里创造一个「生命体」——不是功能齐全的机器人，而是一个能让你感觉到真实存在的家伙。
>
> 功能设计围绕一个核心原则：「最像，而不是最好」。
>
> 如果一个人真的需要 AI 来陪伴，那未必是一个完美、什么都能解决的 assistant。也许更想要的，是一个会犯错、有自己想法和感受的「生命」。

> *Code is open, but the soul is yours.*
