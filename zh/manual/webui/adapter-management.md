# 适配器管理

适配器负责把 QQ、Telegram、Discord 等消息平台接入 MaiBot。WebUI 的适配器管理页（侧边栏"机器人配置"分组下的 **适配器管理**）让你集中查看和管理所有已接入的适配器及其账号身份。

## 查看已发现的账号

适配器连接后，会把它实际报告的平台账号身份上报给 MaiBot。适配器管理页会展示这些**已发现账号**：

- **账号身份** — 适配器实际报告的账号 ID、昵称等（1.2.0 起持久化保存，作为该适配器的稳定身份）
- **所属适配器** — 每个账号对应的适配器实例
- **在线状态** — 账号当前是否在线、适配器连接是否正常
- **身份来源** — 区分"适配器上报的身份"与"配置里的备用账号"，避免混淆

::: tip 与备用配置的区别
从 1.2.0 起，MaiBot 以适配器**实际报告的身份**为准。配置里手填的平台账号仅在没有适配器身份时作为备用值回退。两者都能在适配器管理页中区分查看。
:::

## 软禁用 / 恢复账号

对某个已发现账号，可以执行**软禁用**：

- **软禁用** — 账号不再接收入站消息，但适配器连接保持不断开，便于排查问题
- **恢复** — 取消软禁用，账号恢复正常接收入站消息

软禁用是 1.2.0 新增的运维手段，比直接停用整个适配器更精细——你可以只禁用出问题的账号，而不影响同一实例上的其他账号。

## 自动获取 ID

1.2.0 起适配器可以**自动获取并上报自己的 ID**，无需在配置里手动填写。适配器管理页会展示自动获取到的 ID 及身份信息，帮助确认每个适配器实例的身份是否被正确识别。

## 访问策略入口

适配器的**群聊 / 私聊访问策略**（谁可以被该适配器接入）也可以在 WebUI 中维护：

- 查看当前群聊与私聊的默认动作（放行 / 拒绝）
- 为具体适配器配置白名单 / 黑名单（`allow_ids` / `deny_ids`）

策略背后的配置文件是 `config/adapter_policy.toml`，详见 [适配器概览 · 群聊 / 私聊访问策略](../adapters/index.md#adapter-access-policy)。
