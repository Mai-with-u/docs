# 适配器管理

适配器负责把 QQ、邮件、iMessage 等消息平台接入 MaiBot。WebUI 的适配器管理页（侧边栏「配置管理」分组下的 **适配器设置**，`/adapter-management`）让你集中查看和管理所有已接入的适配器及其账号身份。

![适配器管理](/images/webui/adapter-management.webp)

## 查看已发现的账号

适配器连接后，会把它实际报告的平台账号身份上报给 MaiBot。点适配器管理页顶部「全局默认规则」卡片右侧的 **平台账号** 折叠按钮，在浮层里查看这些**已发现账号**：

- **账号身份** — 适配器实际报告的账号 ID、昵称等
- **所属适配器** — 每个账号对应的适配器实例
- **在线状态** — 账号当前是否在线、适配器连接是否正常
- **身份来源** — 区分「适配器已发现账号」与「备用平台账号」，避免混淆

适配器已发现账号渲染成紧凑卡片：平台名、账号 ID、「在线 / 离线」徽标和最近一次上报时间；手动填写的平台 / 账号用的是同款卡片，带铅笔（编辑）和垃圾桶（删除）图标，平台或账号没填全的行会保持编辑态，不会出现空白卡片。

## 自动获取 ID

1.2.0 起适配器可以**自动获取并上报自己的 ID**，无需在配置里手动填写。适配器管理页会展示自动获取到的 ID 及身份信息，帮助确认每个适配器实例的身份是否被正确识别。

## 访问策略入口

适配器的**群聊 / 私聊访问策略**（谁可以被该适配器接入）在 WebUI 里有两个入口：

- **适配器管理页顶部的「全局默认规则」卡片** — 分别设置群聊与私聊在没有任何具体规则命中时的默认动作（**接收消息** / **不接收**）。
- **适配器插件配置页的「黑白名单规则」页签** — 只在 `plugin_type = adapter` 的插件上出现，按适配器实例配置具体的 `allow_ids` / `deny_ids`

### 黑白名单规则面板

「黑白名单规则」面板在选中一个适配器后打开：

- **模式提示** — 每个列表下方有一行说明，写清当前是「黑名单模式：接收所有群聊消息，只需在『不接收消息的聊天ID』中添加要屏蔽的群号」还是对应的白名单表述
- **失效列表置灰** — 默认「接收所有消息」时「接收消息的聊天ID」整块置灰且空列表禁填；默认「默认不接收消息」时「不接收消息的聊天ID」同样置灰，避免往不起作用的列表里填值
- **当前账号徽标** — 工具栏显示「当前账号 ID：xxx」；这个适配器实例没有专属规则时显示「无专属规则，按全局默认生效」
- **换号登录提示** — 规则按账号 ID 区分。切换到另一个账号登录后会弹提示：当前账号将新建自己的规则，历史账号的规则仍留在配置里但不再生效
- **工具栏位置** — 当前账号徽标、保存状态和「保存」按钮渲染在页签同一行，不用滚到面板顶部

### 策略分组

同一适配器的规则可以保存成**多组策略**，按场景切换生效（比如「日常 / 测试 / 维护」各一套）：

- **分组切换** — 工具栏上的下拉框显示当前生效的分组，切换后立即保存并生效；切换时会把正在编辑的草稿先存入当前分组，不会丢改动
- **新建分组** — 点「＋」新建策略分组：新分组默认继承全局设置、名单为空，名称不能与已有分组重复；创建后从下拉框切换过去
- **复制当前组** — 点「复制」以当前分组的全部规则创建新分组，创建后仍停留在当前分组
- **管理分组** — 点「管理」打开分组列表，可删除不需要的分组；**当前生效的分组不能删除**，需先切换到其他分组
- **默认分组** — 升级前已有的规则会完整保留在名为「默认分组」的分组里，不用重新配置
