# 统计与观察

WebUI 提供两套看运行情况的面板：**首页与详细统计**回答「花了多少、用了多少」，**麦麦观察**回答「麦麦刚才在想什么」。

## 详细统计

侧边栏「高级工具 → 详细统计数据」（`/statistics`）。页头显示统计截止时间和统计时段，可以切换时间段查看：

::: fields
- **模型调用** — 每次请求的模型、任务、耗时。
- **Token 与费用** — 按模型、任务组、时间分布。
- **消息与在线时长** — 收发条数与运行时间。
- **缓存** — 命中与未命中的对比。
:::

图表支持按维度切换，明细表格可展开；数据为空时页面显示「当前统计时段暂无数据」。

首页的统计卡片是同一批数据的概览，点卡片可以跳到详细统计。

## 麦麦观察

侧边栏「麦麦观察」（`/observation`，实时监控在 `/monitor`）。这里按聊天流展示麦麦的思考与回复过程：

::: fields
- **思考过程** — Planner 的思考、工具调用与结果，按轮次分组，可收起展开。
- **回复内容** — 实际发出的文字、图片、表情与引用。
- **等待与防抖** — 当前是否在等待、防抖还剩多久。
- **上下文裁切** — 上下文过长时的裁剪记录。
- **工具执行状态** — 悬浮查看每个工具的执行状态与耗时。
:::

输入框可以切换「聊天」与「答疑」两种模式，答疑见[麦麦答疑](./ai-help.md)。

## 推理过程

侧边栏「推理过程」（`/reasoning-process`）保存每一轮的推理记录：

::: fields
- **记录列表** — 按时间倒序，可筛选聊天流。
- **阶段详情** — 每轮 Planner 与 Replyer 的实际提示词阶段。
- **工具调用记录** — 关联到具体轮的调用参数与结果。
- **重放** — 用保存的记录重新回放一轮推理。
- **导入** — 从外部文件导入推理记录用于排查。
:::

推理记录会占用磁盘并随历史增长，长期运行时注意实例空间。

## 观察页能做的判断

::: fields
- **麦麦不回复** — 看该聊天流是否在等待、是否被防抖合并、是否命中访问策略被过滤。
- **回复内容跑偏** — 展开该轮思考，确认是记忆检索、工具结果还是插件改写了回复。
- **模型报错** — 在工具调用与阶段详情里定位到具体请求，再对照[模型配置](../configuration/model-config.md)。
- **花费异常** — 在详细统计里按模型和任务组看分布，判断是哪一类请求在涨。
:::

## 验证与排错

**验证**：在「麦麦聊天」发一句话，然后打开麦麦观察，能看到这一轮的思考、工具调用与最终回复；详细统计里的模型调用数应该增加。

- **观察页没有新记录** — 确认页面连的是当前 Bot；切换 Bot 后需要重新选择聊天流。
- **统计数字为 0** — 切换统计时段；统计按任务记录写入，刚启动时可能还没有数据。
- **推理记录占用太大** — 定期清理旧的推理记录，或降低记录保留量。
- **首页卡片与详细统计对不上** — 两者的统计时段可能不同，先对齐时段再比较。
