# 学习管理

侧边栏「资源管理 → 学习」（`/resource/learning`）集中管理麦麦从聊天里学到的东西，分「表达方式」「黑话」「表情包」三个标签。

## 表达方式

麦麦会在聊天里学习别人怎么说话：什么情境、用什么风格、说过哪些句子。列表按情境分行，显示情境、风格和精选状态。

![表达方式](/images/webui/expression.webp)

- **聊天范围** — 左侧按聊天流或共享组过滤，「全部」显示所有来源；每个范围旁边有「学习」和「使用」开关
- **排序** — 「最近活跃」按最近使用时间排序，「仅精选」只显示标为精选的表达
- **新增 / 编辑 / 删除** — 手动补充表达方式，或修正学错的内容
- **导出** — 把当前范围的表达方式导出成文件，方便备份或迁移
- **卡片审核** — 用滑卡方式逐条「通过」或「拒绝」：通过的表达才会被使用，拒绝的会直接删除；旁边可以查看「AI审核记录」
- **聚类** — 「更多操作」里的「聚类」按语义相似度浏览表达方式

## 黑话

黑话标签记录群里的梗和缩写，以及它们的含义和出现次数。

![黑话](/images/webui/jargon.webp)

- 顶部统计总数量、已确认黑话和推断完成的数量
- 列表显示内容、含义、来源聊天、是否手动添加和遇见次数
- 「新增黑话」手动录入；「查看/编辑」修正含义；「删除」移除
- 「导出黑话」导出当前范围的黑话

## 表情包

表情包标签管理麦麦能发的表情：上传、审核、封禁和删除。

![表情包](/images/webui/emoji.webp)

- **状态筛选** — 已注册、待审核 · 已识别、待审核 · 未识别、已禁用、全部
- **格式与排序** — 按格式筛选，按注册时间或上传时间排序，切换卡片大小
- **上传** — 添加新表情，上传后自动识别内容，再按识别结果进入「待审核 · 已识别」或「待审核 · 未识别」
- **卡片操作** — 编辑描述、封禁（不再发送）、删除

## 学习范围

表达和黑话的学习范围由 `[expression].learning_list` 和 `[jargon].learning_list` 控制，每个聊天流也可以在聊天流设置里单独开关学习和使用。范围和黑名单的写法见 [Bot 配置 → 学习系统](../configuration/bot-config.md#学习系统)。
