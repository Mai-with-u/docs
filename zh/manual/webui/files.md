# 文件与附件

WebUI 的「文件」页面按聊天管理附件：上传、下载、在线阅读文本、清理缓存和删除原件。文件功能本身要在「能力 → 文件功能」打开，详见[文件功能](../files.md)。

## 页面结构

左侧按聊天实际名称筛选，右侧是文件列表和存储用量。列表显示文件名、大小、类型、所属聊天和最后访问时间。

- 按聊天筛选时，只列出与该聊天绑定的文件。
- 不选聊天时列出实例内的全部文件，管理员可以看到跨聊天的全部内容。
- 顶部显示当前实例的存储配额占用。

## 常用操作

::: fields
- **上传** — 选择目标聊天后上传，文件登记到该聊天。
- **下载** — 生成一次性传输链接，默认五分钟失效。
- **在线阅读** — 文本类文件可以直接看正文，按字符分页，每次最多 32000 字符。
- **发送到聊天** — 选择目标聊天并确认后跨聊天发送；普通工具和插件 SDK 没有这个授权。
- **删除** — 删除原件。
:::

移除聊天草稿里的附件不会删除原件；原件只能在这里或通过工具删除。

## 支持的格式

存储和收发不限制扩展名，Office、PDF 等二进制文件同样可以上传、下载和发送，但内容不会被解析。

在线阅读支持 UTF-8、带 BOM 的 UTF-16，以及显式指定 GB18030 的文本；不执行文档脚本或宏。

## 配额与清理

::: fields
- **`max_file_mib`** — 单文件上限，默认 50 MiB。
- **`max_storage_gib`** — 实例存储配额，默认 10 GiB。
- **`max_text_mib`** — 文本解析上限，默认 8 MiB，最大 50 MiB。
- **`cache_days`** — 平台下载缓存最后访问后保留天数，默认 30 天。
:::

达到配额会拒绝新增，不会自动删原件。平台下载的缓存按 `cache_days` 清理；本地上传和生成的内容属于原件，保留到手动删除。

## 验证与排错

**验证**：在「麦麦聊天」上传一个文本文件并随消息发送，然后打开「文件」页面按该聊天筛选，能看到文件、能下载、能在线阅读。

- **页面提示文件功能未启用** — 到「能力 → 文件功能」打开 `capabilities.files`。
- **上传被拒绝** — 检查单文件大小与实例剩余配额；配额不足一个单文件额度时也会拒绝开始传输。
- **下载链接打不开** — 传输令牌默认五分钟失效，重新签发一次即可。
- **文本读不出来** — 超过 `max_text_mib` 的文件不解析正文，但仍可下载；编码不支持时也会失败。
- **发送到其他聊天被拒** — 跨聊天发送需要管理员在页面上选择目标聊天并确认。
