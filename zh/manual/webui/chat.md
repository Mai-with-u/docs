# 与麦麦聊天

侧边栏「概览 → 麦麦聊天」（`/chat`）是 WebUI 自带的聊天窗口，不经过 QQ 等平台适配器：消息直接进入 MaiBot 的内部聊天流，适合还没接平台、或者想单独试试回复效果的时候。

![麦麦聊天](/images/webui/chat.webp)

## 本地聊天室

左侧「与麦麦聊天」下面就是本地聊天室，显示麦麦的头像和连接状态。打开页面时已经自动连接，在底部输入框直接发消息即可。

- **发送** — 按 Enter 发送，Shift + Enter 换行
- **身份** — 输入框上方的「以「人类」发送」可以改你在这里的昵称和头像
- **图片** — 「添加图片」选图后随消息一起发出
- **附件** — 回形针按钮发送文件，需要先开启[文件功能](../configuration/bot-config.md#文件)
- **表情包** — 「用户表情包」里选一个已有表情发给麦麦
- **顶栏操作** — 「会话信息」显示当前消息数和连接状态；「清空当前显示」只清空网页上的消息，不删除历史记录

本地聊天室同样要经过规划与回复模型，没有配置模型时麦麦不会回复。

## 观察真实聊天流

「麦麦的聊天流」列出麦麦已经建立的所有聊天流，包括内部私聊和各平台的群聊、私聊，按最近活跃时间排序；每一项显示最后一条消息的预览和当前状态。

点开一条聊天流会进入**观察模式**：实时看到麦麦在这个流里的思考过程、工具调用和发出的消息，但不会向平台发送任何内容。这适合排查「麦麦为什么没回」，或者观察它在群里的表现。

每条聊天流右侧的齿轮打开该流的专属设置：

- **会话信息** — Session ID、平台、类型（群聊/私聊）、群号或用户 ID
- **适配器规则** — 该流命中的适配器访问规则和全局默认值
- **发言频率规则** — 全局默认频率，以及按时间段生效的规则；可以给当前聊天流新增专属规则
- **聊天 Prompt** — 该流的群聊/私聊提示词，还可以追加只属于当前流的额外 Prompt
- **表达与黑话** — 分别开关「使用」和「学习」，并显示命中的学习范围
- **删除聊天流** — 清理该流的所有消息、学习内容、工具记录和统计，需要输入完整 session_id 确认
