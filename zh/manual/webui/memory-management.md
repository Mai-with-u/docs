# 查看和管理记忆

MaiBot 会把聊天中学到的内容存进长期记忆，就像人的记忆一样。侧边栏「麦麦资源管理」分组下的 **长期记忆**（`/resource/knowledge-base`）页面集中管理这些记忆：查询、导入、修正、删除、调优都在这里。

![长期记忆](/images/webui/knowledge-base.webp)

## 记忆总览

打开「长期记忆」页，标签栏按用途分区：

- **记忆查询** — 搜索记忆内容，内部再分「文字记录」和「人物画像」两个视图
- **图片记忆** — 查看图片资产、图片认知与关联记忆，发起以图搜图和历史回填
- **记忆流** — 核对每个聊天流的记忆变动
- **导入导出** — 导入资料，并导出、安装可分享的记忆包
- **记忆检修** — 维护记忆状态并修正记忆内容
- **记忆抹除** — 批量抹除与历史回溯

右上角的「更多操作」菜单里还有 **查看记忆状态** 和 **打开图谱**；旧链接里的 `tab=graph` 仍能直接打开图谱。

## 搜索记忆

在「记忆查询」里输入关键词（比如「游戏」「美食」），可以按时间、按用户筛选，看某段时间或和谁的聊天记忆。

「记忆查询」内部再分「文字记录」和「人物画像」两个视图：前者查段落等权威记录，后者查人物档案（见[人物画像](#人物画像)）。

![记忆查询](/images/webui/knowledge-query.webp)

## 知识图谱

图谱像思维导图一样显示概念之间的关系，入口在页面右上角「更多操作 → 打开图谱」，旧链接里的 `tab=graph` 也能直接打开：

- 每个节点是一个概念（比如「原神」）
- 连线表示关系（比如「原神-游戏」）
- 点击节点看详细信息

独立的**长期记忆图谱**页（`/resource/knowledge-graph`）提供全屏可视化：

![长期记忆图谱](/images/webui/knowledge-graph.webp)

## 图片记忆

「图片记忆」标签管理麦麦"看过的图"。它需要先配置图片嵌入模型（`model_config.toml` 的 `[model_task_config.image_embedding]`）；没配时图片和认知照常保存，但页面会显示检索不可用。相关参数见 [A_Memorix 配置 → 图片记忆](../configuration/amemorix-config.md#图片记忆)。

这个标签能做什么：

- **查看图片资产与出现记录** — 缩略图、来源聊天流、认知（用户说明、模型描述、手工修正）及其关联的段落、实体、关系和 Episode
- **以图搜图** — 选择库内一张图片发起相似搜索，可调整相似度阈值。结果会区分**精确同图**和**视觉相似**，并展示分数、真实聊天名称、认知、关联知识和各阶段耗时
- **历史回填** — 点击「预览历史回填」先分类扫描历史消息（可处理、已处理、来源缺失、聊天流缺失、文件缺失、图片无效、写入失败），确认后再执行；执行会忽略预览后新到的消息
- **任务诊断** — 查看图片嵌入任务与描述补偿任务列表，按状态筛选，查看重试次数、最后错误、租约期限，以及当前模型指纹下的索引进度
- **认知确认与修正、记录删除** — 确认或修正图片认知，删除错误的关联或出现记录

**排错提示**：

- 图片检索一直显示"等待构建" → 确认 `image_embedding` 任务已配置可用的图片嵌入模型
- 显示"模型不可用" → 模型探测失败，检查服务商是否支持图片输入或密钥是否有效；失败会按 `probe_retry_seconds` 自动重试
- 历史回填出现大量"文件缺失" → 历史图片二进制已被清理，属正常现象，不影响新图片入库

## 记忆流

核对每个聊天流的记忆变动：

![审计时间线](/images/webui/knowledge-timeline.webp)

- 按时间倒序分页展示记忆审计事件（新增、更新、删除等）

## 导入与记忆包

「导入导出」标签可以手动教 MaiBot 新知识，也能把已有记忆打包带走：

![导入记忆](/images/webui/knowledge-import.webp)

1. 选择导入方式：**资料导入**（文本、文件或文件夹）、LPMM OpenIE、LPMM 转换
2. 粘贴文本或上传文件
3. 按需在「导入参数」弹窗中设置公共与高级参数
4. 开始导入，任务列表实时显示进度

**记忆包（`.amembundle`）** 用于在一台 MaiBot 和另一台之间迁移或分享记忆：

- **导出** — 选择导出的记忆范围，可预览将包含的段落、实体、关系、图片和未压缩体积；图片可多选，并可勾选"携带直接关联知识"
- **安装** — 先上传预览包检查（体积、图片数、资源检查、向量兼容性），再执行安装；安装内容与检索能力分开显示
- **图片向量复用** — 安装实例的图片嵌入模型与来源一致时直接复用包内向量；模型不一致、缺少向量或模型暂不可用时仍完成内容安装，图片状态显示为"等待构建"，之后按本地模型补建
- **卸载** — 卸载记忆包时会清理包内独占资源；仍被本地聊天或其他包引用的共享图片会保留

**包里有什么** — 记忆包是一个 ZIP，按内容级别打包：

- **`knowledge`（知识级）** — 段落、实体、关系及其向量，等价于一份 LPMM 同语义知识包；适合只迁移"知识"不迁移人物档案
- **`full`（完整级）** — 在知识之外还包含人物画像、情景记忆（Episode）、事实账本、外部引用和生命周期状态；适合整机迁移或完整备份

包内成员包括 `manifest.json`、`knowledge.json`、可选的 `state.json`、段落与关系向量，以及图片记忆的 `images.json`、`images/assets/`（原始图片）和可选的 `vectors/images.npz`（图片向量）。

**容量与兼容**：单包最多 4096 个成员，单个成员解压后不超过 256 MiB，解压总计不超过 1 GiB（旧版 32 成员的限制已放宽）。旧格式（v1）的纯文本包仍可直接安装。安装过程**不调用任何 LLM**：包内向量可用则复用，不可用或缺失时只重建图片向量索引，不会重新做抽取。

## 纠正记忆

发现画像或关系不准确时，通过「记忆检修 → 内容修正」修正：

1. 在人物画像中设置或删除手动 override
2. 在知识图谱中调整节点、关系或权重
3. 使用反馈纠错、删除恢复或重新导入来处理过时内容

普通段落正文目前不提供任意文本编辑入口；需要修正时，建议删除错误来源后重新导入，或通过反馈纠错机制处理。

## 抹除记忆

不想记住某些内容？「记忆抹除」标签支持：

![删除记忆](/images/webui/knowledge-delete.webp)

- 单条删除：找到记忆，点击「删除」
- 批量删除：选择多条，一起删除
- 按来源删除：删除某个聊天流的所有记忆

⚠️ **注意**：删除后进入回收站，还可以恢复

反馈与回滚记录可在「记忆检修」里查看：

![纠错历史](/images/webui/knowledge-feedback.webp)

## 人物画像

MaiBot 会给每个用户建立「画像」：

- 性格特点（开朗、内向等）
- 兴趣爱好（游戏、动漫等）
- 聊天习惯（爱用表情包、说话方式等）

在「人物画像」标签或**人物信息管理**页（`/resource/person`）可以：

![人物信息管理](/images/webui/person.webp)

- 查看画像
- 修改不准确的描述
- 给好友添加备注

## 检索调优

如果 MaiBot 记性不好，可以运行调优任务优化检索效果（「记忆检修 → 检索调优」）：

![检索调优](/images/webui/knowledge-tuning.webp)

- 页面常驻内容只保留说明与开始按钮
- 调优参数收在「调优参数」弹窗里，只影响下一次调优任务，一般保持默认即可
- 任务完成后可查看评估结果，验证通过可一键「应用推荐结果」

## 运行时维护

「记忆检修 → 状态维护」提供运行时自检、自动保存开关、向量重建、段落向量回填、图片资产核对、导入任务和删除操作记录等运维入口。页面右上角的「更多操作 → 查看记忆状态」弹窗集中展示运行状态（含向量重建与刷新数据）。

![状态维护](/images/webui/knowledge-maintenance.webp)

## 使用建议

### 日常维护

- 定期查看记忆，删除无用内容
- 发现错误及时纠正
- 重要信息可以手动强化

### 提升效果

- 教机器人专业知识，让它更聪明
- 完善人物画像，让对话更贴心
- 合理设置记忆容量，平衡性能和效果

## 验证与排错

**验证**：导入一段文本，任务完成后在「记忆查询」里能搜到相关内容。

**导入任务一直排队或失败？**

- 确认已配置可用的模型服务商（导入需要模型做抽取和向量化）
- 查看任务详情里的失败原因

**记忆查询搜不到？**

- 确认记忆已导入成功（任务状态为「已完成」）
- 检查向量是否已构建，必要时在「状态维护」里重建向量

**图片搜不到或一直"等待构建"？**

- 确认 `model_config.toml` 的 `[model_task_config.image_embedding]` 已配置支持图片输入的嵌入模型
- 查看「图片记忆 → 任务诊断」里的失败原因和重试次数；模型不可用时页面会明确显示，不会伪装成等待

**记忆会保存多久？**

默认长期保存。记忆演化会让旧关系权重逐渐衰减，低权重内容可能被标记为待裁剪；具体行为由 A_Memorix 的记忆演化配置控制。

**记忆会泄露隐私吗？**

记忆数据默认存储在本地目录中。生成摘要、画像、纠错或向量时可能会调用你配置的模型服务，请根据自己的部署方式和模型提供商确认数据边界。
