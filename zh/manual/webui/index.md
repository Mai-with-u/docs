# WebUI

WebUI 是 MaiBot 的管理页面：登录后可以在浏览器里改配置、和麦麦聊天、看它的思考过程、管理插件和数据，不用碰 TOML 文件。

## 首次登录

启动宿主后，终端会打印 WebUI 地址和本次运行的临时登录密码：

```text
MaiBot 宿主已启动：/MaiMBot
WebUI：http://127.0.0.1:8001/bots#ticket=...（登录链接一分钟内有效）
WebUI 临时登录密码：3f2c9a5b...
可用 maibot host status/start/stop/restart 管理 Bot；Ctrl+C 关闭宿主。
```

点日志里的链接直接进入，或打开 `http://127.0.0.1:8001/` 粘贴这串临时登录密码。首次登录会进入配置向导，其中一步要求设置固定密码。

::: fields
- **临时登录密码** — 每次启动都会重新生成，只在本次宿主运行期间有效；设好固定密码后，日志不再打印这一行。
- **登录链接** — 带一次性票据，一分钟内有效；过期后改在登录页输入密码。
- **固定密码** — 长度至少 10 位，同时包含大写字母、小写字母和特殊符号，例如 `MaiBot-Docs-2026!`。
- **保存后** — 旧密码立即失效，用新密码重新登录继续向导。
:::

登录会话有效期 8 小时。固定密码下的会话在宿主重启后仍可复用原 Cookie 自动进入，重启不延长有效期。浏览器只保存随机票号，数据库只保存绑定当前密码的票号摘要；退出登录撤销当前会话，修改或重置密码撤销旧会话。

远程机器上不方便复制密码时，执行 `maibot host open-webui --directory <工作区>` 取一次性登录链接（60 秒内有效）。

## 布局

WebUI 用侧边栏组织页面，分组是：概览、配置管理、资源管理、扩展集成、高级工具。

::: fields
- **首页** — 点侧栏顶部的 Logo 回到首页，首页汇总运行状态、用量和快捷入口。
- **切换 Bot** — 入口在侧栏底部。选中后配置、聊天、插件和资源页面都读写该 Bot 的数据；所有 Bot 都停止时仍可在这里管理。
- **界面布局** — 在 WEBUI设置的「外观」里选「经典」或「麦麦观察」：经典布局保留顶栏和卡片首页，麦麦观察布局去掉顶栏，侧栏上半区是设置、下半区是所有对话。只在桌面宽度生效。
:::

侧栏底部的另一项是更新入口，有新版本时会直接显示提醒。

## 网络与登录设置

WebUI 自身的监听地址、端口和登录策略保存在宿主配置 `host/config.toml` 的 `[webui]` 段，改完需要重启宿主：

::: code-group

```toml [host/config.toml ~vscode-icons:file-type-toml~]
[webui]
enabled = true                       # 是否启用 WebUI
hosts = ["127.0.0.1", "::1"]         # 监听地址列表；远程访问改为 ["0.0.0.0", "::"]
port = 8001                          # WebUI 与文件传输共用的端口
public_base_url = ""                 # 外部可访问的 HTTP(S) 地址，用于生成文件链接；留空用本机地址
ssl_certfile = ""                    # HTTPS 证书路径；与 ssl_keyfile 必须同时填写
ssl_keyfile = ""                     # HTTPS 私钥路径
secure_cookie = false                # 只允许通过 HTTPS 携带登录 Cookie
anti_crawler_mode = "basic"          # 防爬虫：false 关闭 / basic 只记录 / loose 宽松拦截 / strict 严格拦截
allowed_ips = "127.0.0.1"            # 不受防爬虫限制的 IP，逗号分隔，支持 CIDR 与通配符
trusted_proxies = ""                 # 信任的反向代理 IP，逗号分隔
trust_xff = false                    # 仅当直连地址在 trusted_proxies 中时采用 X-Forwarded-For
```

:::

这些设置也可以直接在「麦麦设置 → 公共设置」里改，保存后同样需要重启宿主。旧实例首次进入宿主时，配置里的监听地址、端口、证书与文件传输地址会被读取并生成这份宿主配置。

端口由宿主统一持有，所有 Bot 共用；文件传输地址统一取宿主的 `webui.public_base_url`，`bot_config.toml` 里没有监听相关的配置。

## 忘记密码

还能登录时：进 **WEBUI设置**（侧栏的齿轮）→「安全」，在那里修改或重新生成访问密码。

已经登录不了时：

::: steps
1. 关闭宿主。
2. 删除工作区的 `host/webui.json`。
3. 重新启动宿主，用新打印的临时登录密码进去，再按向导设置固定密码。
:::

## 更新主程序

**设置 → 关于** 可以检查并更新主程序。检测到新版本时侧栏底部会出现更新卡片。

::: fields
- **源码部署** — 沿用官方分支快进更新；有未提交的修改或分支分叉会阻止更新。
- **程序包安装** — 从 PyPI 或所选镜像更新程序本身，实例目录里的配置、数据和插件不受影响。
:::

更新流程会先停止全部 Bot，保留登记的期望状态，再关闭宿主；更新完成后按原状态恢复。预检失败不会打断 Bot，更新失败沿用原更新器的回滚。详细说明见[uv 安装](../deployment/uv-tool.md)。

## 验证与排错

**验证**：浏览器打开 `http://127.0.0.1:8001/` 能进登录页；用终端打印的临时登录密码进去后，侧栏能看到完整分组，底部能切换 Bot。

- **打不开页面** — 确认宿主正在运行并打印了访问地址；检查 `host/config.toml` 的 `[webui].enabled`，以及端口是否被占用。
- **提示密码错误** — 临时登录密码每次启动都会变，用本次启动打印的值；复制时别带空格或换行。
- **设置固定密码后进不去** — 保存后旧密码立即失效，其他浏览器上的登录也会被踢下线，用新密码重新登录；实在不行删 `host/webui.json` 重置。
- **登录过一会儿就掉线** — 会话有效期 8 小时，过期或宿主认证状态变化会失效；重新登录即可。
- **改了监听地址没生效** — `[webui]` 的地址和端口需要重启宿主才生效，热重载不会重新绑定监听。
