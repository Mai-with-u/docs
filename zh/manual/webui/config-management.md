## 麦麦设置

打开「麦麦设置」页，顶部有两个标签和一个省略号菜单：

![麦麦设置](/images/webui/config-bot.webp)

- **详细设置** — 完整的分节表单
- **命令管理** — 插件命令与执行权限
- **⋮ 更多设置** — 手动保存、共享组设置、源文件编辑

### 详细设置

完整的分节表单，覆盖 `bot_config.toml` 的所有配置节（聊天、记忆、表情包、语音、MCP 等）。不确定的选项悬停鼠标看说明。

![详细设置](/images/webui/config-bot-detail.webp)

### 把常用设置页钉在顶部

「麦麦设置」的栏目很多。页面标题旁边是一个**下拉列表**，所有栏目都在里面。可以将常去的栏目钉住：打开下拉列表，点栏目右边的图钉，它就会固定在标题右侧。

### 命令管理

查看所有已注册的插件命令并配置执行权限，见[命令管理](./command-management.md)。

### 共享组设置

省略号菜单里的 **共享组设置** 用来把多个聊天流编成一组，让它们共享同一套表达方式、黑话或长期记忆：

- **表达** 共享组写 `expression_groups`，**黑话** 共享组写 `jargon_groups`，**记忆** 共享组写 `a_memorix.shared_memory_groups`
- 新建共享组、添加聊天、移除单个聊天、删除整个共享组
- 打开 `a_memorix.global_memory_sharing_enabled` 后，记忆共享组变为只读


### 源文件编辑

省略号菜单里的 **源文件编辑** 直接编辑 `bot_config.toml` 原文，适合懂 TOML 的用户：

![源文件编辑](/images/webui/config-bot-source.webp)

## 模型管理

「模型管理」页管理模型服务商、模型和任务分配：

![模型管理](/images/webui/config-model.webp)

- **模型设置** — 左侧选择服务商，右侧编辑 API 地址、Key 和模型列表，可点「测试连接」验证
- **功能分配** — 把思考、回复、视觉等任务分配给具体模型

![功能分配](/images/webui/config-model-tasks.webp)

- **配置副本** — 保存当前配置副本、管理历史副本，方便回滚


### 分时价格

模型价格除了默认的输入 / 输出 / 缓存单价，还可以按每天的时间段分别计价：

- 编辑模型时展开 **分时价格** 区块，点「添加时段」新增一行
- 每行填 **开始时间**、**结束时间**（`HH:MM`，服务器本地时间）和该时段的 **输入价格**、**输出价格**、**缓存价格**（元 / M token）
- 结束时间早于开始时间表示跨午夜，结束时间旁会显示「次日」
- 时段按「包含开始、不包含结束」计价，未匹配任何时段时用默认价格；时段之间不能重叠，开始与结束不能相同

### 思考开关

模型编辑弹窗里的「启用思考」开关按服务商模板动态显示

- `thinking.type` 格式（智谱 / Kimi / MiniMax / 豆包等）— 可开可关，关闭写入 `disabled`
- `enable_thinking` 格式（百炼 / 硅基流动等）
- `reasoning_effort` 格式（阶跃 / OpenAI / xAI 等推理模型）— 思考常开，只能调整力度档位，不能关闭

豆包与 Qwen 支持配置思考预算。具体参数名、力度档位与预算字段见[模型额外参数](../configuration/model-extra-params.md)。

### 模型测试

点击模型的闪电图标可以对模型进行测试，会使用测试请求评估模型的可用性。注意，这不代表模型在实际任务中的反应速度，由于实际任务可能会有更长的上下文和复杂的任务，可能会需要更多时间。

## 修改建议

### 新手推荐

- 先改**机器人昵称**和**人格设定**（都在「基础 → 身份与人格」），让机器人有个性
- 调**回复速度**，太快太慢都不好
- 试试**人格设置**，让机器人更有趣

### 进阶玩法

- 配置**多个 AI 模型**，不同任务用不同模型
- 设置**关键词回复**，让机器人更智能
- 调整**记忆参数**，记住更多聊天内容
