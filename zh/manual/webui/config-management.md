# 在浏览器里改配置

不用编辑文件，在 WebUI 里点点鼠标就能改 MaiBot 的设置。侧边栏「麦麦配置编辑」分组下的 **麦麦设置**（`/config/bot`）编辑 `bot_config.toml`，**模型管理**（`/config/model`）编辑 `model_config.toml`。

## 麦麦设置

打开「麦麦设置」页，顶部只有 **详细设置** 和 **命令管理** 两个标签，其余能力从 1.3.1 起收进右上角的省略号（更多设置）菜单：

![麦麦设置](/images/webui/config-bot.webp)

- **详细设置** — 完整的分节表单
- **命令管理** — 插件命令与执行权限
- **⋮ 更多设置** — 手动保存、共享组设置、源文件编辑

原来顶部的四个标签（核心设置 / 详细设置 / 命令管理 / 源文件）已改为两个标签 + 一个省略号菜单；「核心设置」页已删除，其位置由「共享组设置」接替。

### 详细设置

完整的分节表单，覆盖 `bot_config.toml` 的所有配置节（聊天、记忆、表情包、语音、MCP 等）。不确定的选项悬停鼠标看说明。

![详细设置](/images/webui/config-bot-detail.webp)

### 命令管理

查看所有已注册的插件命令并配置执行权限，见[命令管理](./command-management.md)。

### 共享组设置

省略号菜单里的 **共享组设置** 用来把多个聊天流编成一组，让它们共享同一套表达方式、黑话或长期记忆：

- **表达** 共享组写 `expression_groups`，**黑话** 共享组写 `jargon_groups`，**记忆** 共享组写 `a_memorix.shared_memory_groups`
- 新建共享组、添加聊天、移除单个聊天、删除整个共享组
- 打开 `a_memorix.global_memory_sharing_enabled` 后，记忆共享组变为只读
- 也可以从「详细设置」里 `a_memorix` 的共享记忆组字段旁的「共享组设置」按钮直达，链接形如 `/config/bot?mode=groups&kind=memory`

页面结构与「添加聊天」弹窗的细节见[聊天管理](./chat-stats.md)。

### 源文件编辑

省略号菜单里的 **源文件编辑** 直接编辑 `bot_config.toml` 原文，适合懂 TOML 的用户：

![源文件编辑](/images/webui/config-bot-source.webp)

保存时系统会检查格式，有错会提示；保存成功后按下方规则生效。

### 手动保存

省略号菜单第一项是 **手动保存**。表单模式改动后约 2 秒自动保存，没有未保存改动时该菜单项显示「已保存」并禁用，不必手动点。

切换到其他模式前必须先保存：有未保存改动时点「共享组设置」或「源文件编辑」会弹出「切换失败 / 请先保存当前更改」的提示。

## 模型管理

「模型管理」页管理模型服务商、模型和任务分配：

![模型管理](/images/webui/config-model.webp)

- **模型设置** — 左侧选择服务商，右侧编辑 API 地址、Key 和模型列表，可点「测试连接」验证
- **功能分配** — 把思考、回复、视觉等任务分配给具体模型

![功能分配](/images/webui/config-model-tasks.webp)

- **配置副本** — 保存当前配置副本、管理历史副本，方便回滚

「功能分配」里选中 `planner` 或 `replyer` 任务时，卡片下方会显示一行运行摘要：视觉模式（文本 / 多模态 / 自动）与当前生效模型的思考开关状态。

### 分时价格

模型价格除了默认的输入 / 输出 / 缓存单价，还可以按每天的时间段分别计价（1.3.0 起）：

- 编辑模型时展开 **分时价格** 区块，点「添加时段」新增一行
- 每行填 **开始时间**、**结束时间**（`HH:MM`，服务器本地时间）和该时段的 **输入价格**、**输出价格**、**缓存价格**（元 / M token）
- 结束时间早于开始时间表示跨午夜，结束时间旁会显示「次日」
- 时段按「包含开始、不包含结束」计价，未匹配任何时段时用默认价格；时段之间不能重叠，开始与结束不能相同
- 模型卡片和列表里的价格列现在标注为「默认输入价格 / 默认输出价格」，配了时段的模型还会显示「N 个价格时段」

分时价格会写进 `model_config.toml` 的 `price_periods`，字段含义见[模型配置](../configuration/model-config.md)。

### 思考开关

模型编辑弹窗里的「启用思考」开关按服务商模板动态显示（1.3.0 起）：模板没有声明思考参数时不显示开关，DeepSeek 仍走自己的专用段。不同模板写入的参数不同：

- `thinking.type` 格式（智谱 / Kimi / MiniMax / 豆包等）— 可开可关，关闭写入 `disabled`
- `enable_thinking` 格式（百炼 / 硅基流动等）
- `reasoning_effort` 格式（阶跃 / OpenAI / xAI 等推理模型）— 思考常开，只能调整力度档位，不能关闭

豆包与 Qwen 支持配置思考预算。具体参数名、力度档位与预算字段见[模型额外参数](../configuration/model-extra-params.md)。

### 模型测试

「测试连接」会按模型类型选择测试链路（1.3.0 起优化）：

- 判定为嵌入模型时（名称或标识含 `embed`，或挂在 `embedding` / `image_embedding` 任务下）改走嵌入接口测试，而不是对话接口
- 文本嵌入测试返回向量维度，并对比「相近文本 × 相近文本」「相近文本 × 无关文本」两条余弦相似度
- 图片嵌入测试（`image_embedding` 任务，或名称 / 标识含 `vision`、`vl-embedding`）会发送测试图片，对比相同图片与不同图片的相似度

`embedding` 和 `image_embedding` 是单选任务，用下拉框选一个模型，不做模型列表轮询，也不提供选择策略——向量空间必须保持一致。

保存失败时页面右下角会弹出 toast 提示，不会静默丢弃改动。

## 保存与生效

表单模式改动后自动保存（约 2 秒防抖），也可以点省略号菜单里的「手动保存」。配置写入文件后由 MaiBot 的配置监听器重新加载。

**后续请求自动使用新值** — 人格、聊天策略、回复频率、模型服务商、模型和任务分配等运行时配置。

**需要完整重启 MaiBot** — WebUI 的启用状态、监听地址和端口，`maim_message` 的监听与鉴权，MCP 连接，以及插件运行时自身的进程级设置。

插件自己的配置由插件生命周期管理，通常会热更新。完整边界见[配置文件](../configuration/)。

## 修改建议

### 新手推荐

- 先改**机器人名字**和**签名**，让机器人有个性
- 调**回复速度**，太快太慢都不好
- 试试**人格设置**，让机器人更有趣

### 进阶玩法

- 配置**多个 AI 模型**，不同任务用不同模型
- 设置**关键词回复**，让机器人更智能
- 调整**记忆参数**，记住更多聊天内容

## 验证与排错

**验证**：改一个设置（如机器人昵称），保存后刷新页面，值还在说明写入成功。

**保存失败？**

- 自动保存失败会在右下角弹出 toast，写明失败原因；点省略号菜单的「手动保存」重试
- 源文件模式检查 TOML 格式，看错误提示定位行号
- 表单模式看字段旁的红色提示，按提示修正

**切换模式提示「请先保存当前更改」？**

- 有未保存改动时不能切换模式，先点省略号菜单的「手动保存」
- 或切回「详细设置」等两秒让自动保存跑完

**改了没生效？**

- 运行时配置在下一次处理或请求中生效，稍等再试
- 监听端口、MCP 连接等启动项需要完整重启 MaiBot

**改坏了怎么办？**

- 源文件模式改回原来的值再保存
- 或直接编辑 `config/bot_config.toml` 恢复

**分时价格保存被拒？**

- 确认时间格式是 `HH:MM`（00:00–23:59）
- 确认开始时间与结束时间不相同、时段之间没有重叠；跨午夜的时段写成「22:00 → 02:00」

**模型测试一直失败？**

- 嵌入模型不能用对话接口测，确认模型名或标识能被识别为嵌入模型
- 图片嵌入模型需要支持图片输入到向量的协议，普通文本嵌入模型不会走图片测试
