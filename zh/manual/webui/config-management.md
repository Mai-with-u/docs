# 在浏览器里改配置

「麦麦设置」（`/config/bot`）把 `bot_config.toml` 的全部配置节做成分节表单：改完自动保存，也可以手动保存、编辑源文件或管理共享组。

## 三种编辑方式

顶部标签切换「详细设置」和「命令管理」，右侧的 `⋮` 菜单里还有两项：

::: fields
- **详细设置** — 分节表单，覆盖 `bot_config.toml` 的所有配置节。不确定的选项悬停看说明。
- **命令管理** — 插件命令与执行权限，见[命令管理](./command-management.md)。
- **共享组设置** — 把多个聊天流编成一组，让它们共享表达方式、黑话或长期记忆。
- **源文件编辑** — 直接编辑 `bot_config.toml` 原文，适合懂 TOML 的人。
:::

改动会自动保存；想手动控制时用 `⋮` 里的「手动保存」，旁边的状态会显示「保存中 / 自动保存中 / 已保存」。

## 钉住常用栏目

详细设置顶部的栏目条支持钉固：点栏目右侧的图钉按钮把常用栏目固定到前面，方便反复切换。

手机宽度的屏幕上，栏目会排成一行可横滑的胶囊。

## 共享组设置

共享组把多个聊天流编成一组，共享同一套学习成果：

::: fields
- **表达共享组** — 写入 `expression_groups`。
- **黑话共享组** — 写入 `jargon_groups`。
- **记忆共享组** — 写入 `a_memorix.shared_memory_groups`。
:::

打开 `a_memorix.global_memory_sharing_enabled` 后，记忆共享组在页面上变为只读。

## 模型管理

「模型管理」（`/config/model`）管服务商、模型和任务分配：

::: fields
- **模型设置** — 左侧选服务商，右侧编辑 API 地址、Key 和模型列表；可以点「测试连接」验证。
- **功能分配** — 把思考、回复、视觉等任务分配给具体模型，并显示每个模型最近的调用信息。
- **配置副本** — 保存当前配置副本、管理历史副本，方便回滚。
:::

在「公共设置」里维护的服务商、模型与联网服务是所有 Bot 共享的，各 Bot 只选自己的任务模型，详见[多实例](../multi-bot-host.md)。

### 分时价格

模型的「分时价格」可以按每天的时间段分别计价：

- 设置开始、结束时间（`HH:MM`，服务器本地时间）及输入、输出、缓存单价（元 / M token）。
- 结束时间早于开始时间表示跨午夜。
- 时段按「包含开始、不包含结束」计价，未匹配任何时段时用默认价格；时段之间不能重叠，开始与结束不能相同。

### 思考开关

模型编辑弹窗里的「启用思考」按服务商模板动态显示：

::: fields
- **`thinking.type`** — 智谱、Kimi、MiniMax、豆包等；可开可关，关闭写入 `disabled`。
- **`enable_thinking`** — 百炼、硅基流动等。
- **`reasoning_effort`** — 阶跃、OpenAI、xAI 等推理模型；思考常开，只能调整力度档位。
:::

具体参数名、力度档位与思考预算见[模型额外参数](../configuration/model-extra-params.md)。

## 改完生效的时机

大多数配置保存后热重载生效，模型变更对后续请求生效。需要重启宿主的是监听地址与端口、整个 `[maim_message]` 段、`[plugin_runtime]` 的绑定与 IPC 设置、`[log]` 的事件循环看门狗，以及 `host/config.toml` 里的网络与登录设置。

判断方法：保存后看日志有没有配置重载成功的信息；改了监听地址这类启动期设置就重启。

## 验证与排错

**验证**：在「详细设置」里改一个选项并等状态变成「已保存」，再看日志出现配置重载成功的信息，行为应立刻按新值变化。

- **保存失败** — 看页面上的错误提示；字段值非法时后端会点名具体字段。也可以先做语法自检：`python -c "import tomllib; tomllib.load(open('config/bot_config.toml','rb'))"`。
- **改了没生效** — 对照「改完生效的时机」：监听地址与端口、`[maim_message]`、`[plugin_runtime]`、看门狗需要重启宿主。
- **共享组改了没反应** — 记忆共享组在 `a_memorix.global_memory_sharing_enabled` 打开时只读，需要先关掉总共享开关。
- **源文件编辑保存后表单错乱** — 源文件里写坏了结构；用「手动保存」前的状态或配置副本回滚。
