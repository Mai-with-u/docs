# 麦麦答疑

麦麦答疑是 WebUI 内置的答疑 Agent：用自然语言问「这个配置在哪改」「这个插件怎么用」，它去查官方文档、WebUI 索引和插件市场，给出可直接照做的答案。

## 打开

在「麦麦观察」页把输入模式切到「答疑」，输入问题回车即可。答案里会带来源链接和后续建议，右侧是答疑工作进度：当前计划与已加载技能。

答疑会话自动保存，「帮助历史」里能翻到最近的问答，点开可以继续追问，同一会话接着聊。

## 它能查什么

::: fields
- **WebUI 索引** — 页面路径和配置字段，回答「入口在哪」。
- **官方文档** — 检索并读取 docs.maibot.chat 的正文，回答「怎么配」。
- **本地配置** — 读当前实例实际生效的 `bot_config.toml` 与 `model_config.toml`，密钥和令牌自动隐藏。
- **插件市场** — 查插件详情、README，比较兼容性，准备安装。
:::

答疑 Agent 会按问题类型加载技能，单轮最多加载两个：初始化与配置、故障排查、插件使用、插件开发。

## 允许修改插件配置

默认情况下答疑 Agent 只读。要在这一轮里让它真的改插件配置，勾选输入框旁的「允许修改插件配置」（`allow_plugin_config_write`）：仅对本次提问生效，Agent 可以按问题中的要求保存插件配置。

写入只覆盖插件配置，不碰主程序配置、模型密钥和聊天数据。改动会显示在对话里，保存后请核对页面显示的实际值。

## 验证与排错

**验证**：在「麦麦观察」切到答疑模式，问「文件功能在哪开」，答案里应给出「能力 → 文件功能」的入口和一个文档链接。

- **答不出来或答得很泛** — 问题里带上具体对象，比如「QQ 官方适配器的 bot_token 填在哪」。
- **修改插件配置没生效** — 确认勾选了「允许修改插件配置」，并核对对话里显示的实际改动；下一轮提问会重置这个权限。
- **找不到历史会话** — 只保留最近 50 条，更早的会被挤出列表，可以新建会话重新问。
- **回答里带的是旧文档内容** — 答疑读取的是线上官方文档，更新有延迟；与 WebUI 实际显示不一致时以 WebUI 为准。
