# 聊天管理

「麦麦聊天」是 WebUI 里的聊天室：一边是你和麦麦的一对一对话，另一边是它对各个聊天流的观察。所有会话都在同一个页面里切换。

## 会话列表

左侧栏分两组：

::: fields
- **与麦麦聊天** — 你和麦麦的本地聊天室会话，走 `internal / owner` 身份，和桌宠共用同一份聊天记录。
- **麦麦的聊天流** — 麦麦在各平台上的真实聊天流，带「观察」标记，用来查看它和别人的对话。
:::

列表支持按名称搜索，按最近消息排序，显示在线或离线状态。点会话头部的设置按钮可以打开该会话的聊天设置。

## 本地聊天室

本地聊天室支持切换身份和头像：可以编辑昵称、修改头像，也可以新建虚拟身份对话，用来模拟不同用户与麦麦对话。

- 虚拟身份对话的昵称独立处理，不影响 `internal / owner` 的昵称。
- 普通模式下的昵称由主程序统一保存，改一次会同步到其他网页和桌宠。

## 观察聊天流

选中的聊天流右侧显示这个消息流的历史与实时消息。头部显示会话名称、状态与运行标志，可以收起侧栏给对话区腾空间。

在聊天流上悬停可以看到表达与黑话的学习与使用开关、当前回复频率、运行状态和最近消息。

## 会话级设置

单个聊天流的设置可以在会话头部打开，包括：

::: fields
- **回复频率** — 按聊天流调整，见[聊天场景](../chat-scenes.md)。
- **暂停回复** — 仅私聊出现，可以单独暂停或恢复跟随全局。
- **学习开关** — 表达方式与黑话的学习、使用可以分开控制。
:::

## 聊天附件

聊天输入框的回形针可以上传附件并随消息一起发送，最多一次 4 张图片（每张 8 MiB、2500 万像素）。附件的上传、下载和文本阅读见[文件功能](../files.md)。

## 验证与排错

**验证**：在「与麦麦聊天」里发一句话，麦麦应正常回复；切到「麦麦的聊天流」里的某个群聊流，能看到该群的历史消息。

- **聊天室发不出去** — 确认当前 Bot 已启动；Bot 未运行时聊天页只读。
- **观察流列表是空的** — 确认该 Bot 已经接入适配器并收到过消息；新实例还没有历史。
- **改了昵称没同步** — 昵称由主程序保存，保存成功才会同步；检查 `data/internal_chat_profile.json` 是否可写。
- **历史消息重复显示** — 刷新页面重新拉取；持续出现时带上会话 ID 反馈。
