# 接入平台

**适配器负责把 QQ、邮件、语音通话等消息平台接进 MaiBot。** 在 MaiBot 里，**适配器本身就是插件**——安装、启用和管理都在[插件管理](/manual/plugins/)里完成，装好后去插件设置里填连接信息即可。

## 接 QQ 之前，先选一条路线

QQ 有两条接入路线，按你的条件选一条即可：

- **本地客户端登录** — 用你自己的 QQ 号登录（NapCat 或 SnowLuma），功能最全，**推荐 NapCat**；
- **开放平台机器人** — 去 QQ 开放平台申请机器人（AppID），不需要登录任何 QQ 客户端。

两条路线互不冲突，可以同时启用。

::: tip 1.3.0 的适配器变化
MaiBot 1.3.0 需要配合最新版本的 SnowLuma 适配器使用——新版适配器已合并 NapCat 适配器，升级主程序后请同步升级适配器并**重新设置黑白名单**。

另外，从 1.3.0 起适配器插件可以直接使用 MaiBot 内置的群聊 / 私聊黑白名单（`config/adapter_policy.toml`）。
:::

## 可用适配器一览

**维护方标注** — 🏛️ 官方：`Mai-with-u` 组织维护；🌐 社区：第三方作者维护。

### QQ（本地客户端登录）

- [NapCat](./napcat) — 🏛️ 官方推荐。登录你自己的 QQ 号，通过 NapCat 正向 WebSocket 接入，配置最少
- [SnowLuma](./snowluma) — 🏛️ 官方维护。登录你自己的 QQ 号，通过 SnowLuma 接入，支持语音与主动私聊

### QQ（开放平台机器人）

- [QQ 官方](./qq-official) — 🌐 社区维护。AppID + AppSecret 接入 QQ 官方机器人，支持单聊、群聊、文字子频道与频道私信
- [QQBot](./qqbot) — 🌐 社区维护。AppID + AppSecret 接入 QQ 官方 Bot API，支持私聊（C2C）与群聊

### 邮件、iMessage 与语音通话

- [邮件](./email) — 🌐 社区维护。IMAP 收信 + SMTP 回复，把专用机器人邮箱接入 MaiBot
- [QQ 语音通话](./qq-voice-call) — 🌐 社区维护。为 QQ 增加实时语音通话入口，电话里的麦麦复用同一套人设与记忆
- [iMessage](./imessage) — 🌐 社区维护。通过 Photon 云端服务接入 Apple iMessage，无需自备 Mac

::: tip 社区适配器
社区适配器由各自作者持续维护，安装前可以看一眼仓库的更新时间与 README，确认与当前 MaiBot 版本兼容。
:::

## 配置连接的一般套路

适配器通常要配置两类连接：

- **消息平台 → 适配器** — 例如 NapCat 登录 QQ 并把消息推给适配器；开放平台机器人则需先在 QQ 开放平台申请账号。
- **适配器 → MaiBot** — 插件版适配器一般不需要额外配置这一层，只有独立版才需要。

具体怎么申请平台账号、填哪些地址和 Token，见各适配器文档。

## 验证与排错

向对应平台发一条测试消息：

- MaiBot 后台能看到消息日志、且能正常回复 → 成功；
- 没反应时按序检查：平台客户端是否登录 → 适配器是否启动 → 是否连上平台 →（独立版）是否连上 MaiBot → MaiBot 是否就绪。
