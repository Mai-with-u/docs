# 聊天场景

麦麦在群聊和私聊里是两套不同的行为：群聊要读气氛、把握发言频率，私聊要盯住一个人的节奏。这个页面说明这些差异怎么调。

## 发言频率

群聊里麦麦主动说话的频率由「群聊频率」控制，取值 0～1，越小越安静，默认 `1`（按正常频率）。这个值只影响群聊，私聊另有一套暂停开关。

## 动态发言规则组

按场景给不同群设不同发言频率。规则组可以新建、复制和切换，每组里保存若干条规则；只有当前规则组内启用的规则参与匹配。

::: fields
- **`enabled`** — 关闭后保留该规则，但不参与匹配。
- **`platform`** — 生效平台；留空表示不限定平台，`*` 表示任意平台。
- **`item_id`** — 群号或用户 ID；留空表示不限定聊天，`*` 表示任意聊天。
- **`rule_type`** — `group` 或 `private`。
- **`time`** — 生效时间段；留空为兜底，`*` 为全天，也可填 `23:00-02:00`。
- **`value`** — 该规则的发言频率，`0` 更安静，`1` 按正常频率。
:::

群聊规则必须指定平台或群聊 ID；想调整所有群的默认频率，用「群聊频率」，不要在这里写通配规则。

规则组名称不能为空、不能有首尾空白，也不能重名；启用的规则组必须存在，否则配置校验会直接报错。

## 消息防抖

防抖决定一批消息等多久再送去判断。群聊和私聊各有独立档位，默认都是「自然」：

::: fields
- **关闭** — 新消息不等待，直接进入判断。
- **快速** — 安静 1 秒、活跃 3 秒；群聊同人续发 1 秒、换人 0.5 秒。
- **自然** — 默认：安静 2 秒、活跃 5 秒；群聊同人续发 2 秒、换人 0.5 秒。
- **沉稳** — 安静 4 秒、活跃 7 秒；群聊同人续发 4 秒、换人 2 秒。
:::

新批次按上一条有效消息的间隔选择初始等待：超过 30 秒没有有效消息按安静开批，否则按活跃开批。三档共用的上限：裸图开批至少等 4 秒，批次内纯表情包不延长等待，整批最多 8 秒，被 @ 或提及时最多 1 秒。上限优先于其他等待规则。

换档从下一条有效消息起生效，不重置批次或提及上限；选择关闭会结束正在进行的等待。这里的等待时间不包含模型生成和发送耗时。

## 快速反应

「快速反应模式」默认关闭，仅群聊生效：强制 Planner 使用流式请求，思考或输出期间收到新消息时立即打断并带上新消息重新请求。私聊和 wait 唤醒不受这个开关控制。

被打断的思考与输出保留在历史里，可以在麦麦观察中查看。

## 私聊暂停

开启「暂停私聊回复」后，所有私聊只接收消息并维护历史，不进入思考。单个私聊可以通过暂停规则覆盖全局设置：按平台和用户 ID 指定，开关在聊天流设置里切换或恢复跟随全局。

## Focus

Focus 让同组聊天共享一个持续思考的 Planner：所有成员的消息共同进入上下文，工具通过 `session_id` 指定处理目标。

::: fields
- **`focus_mode`** — 总开关，默认关闭。
- **`focus_on_private`** — Focus 是否也作用于私聊，默认关闭。
- **`focus_groups`** — 共享组列表。同组聊天共享 Planner 与完整上下文，不同组独立运行；未匹配任何共享组的聊天使用原本模式。留空时所有聊天都用原本模式。
- **`focus_chat_whitelist`** — 在已匹配共享组的聊天中进一步限制范围；留空表示不额外限制，仍须匹配共享组。
:::

Focus 仍然按各自场景的规则检查准入。连续等待后，提示麦麦延长等待或主动结束对话。

## 回复模板与创意模式

「聊天 → 聊天设置 → 创意模式」对应 `chat.creative_mode`，默认开启。关闭时使用常规多消息模板；开启时使用通用复古模板：人设、群聊注意事项和注意力提示放在 system，聊天记录和回复要求组织成一条 user 消息。

表达习惯、关键词反应、附件参考、重复回复提醒和插件要求在这些模板里都保留。

模型名称或标识包含 `mai_replier` / `mai-replier`，或等于 `v2p1-contract` / `v2p1-raw` 时，该次生成使用 Mai Replier 专用适配，不受创意模式开关影响，也不切换生成语言。插件临时指定模型、候选模型切换和重新生成都会重新判断。

## 引用频率

群聊和私聊的引用（回复时带上原消息）各有独立档位：不引用、偶尔引用、经常引用，默认偶尔引用。经常引用的概率是偶尔引用的两倍。

群聊按固定规律随机决定；私聊结合用户连发条数、发言间隔和回复目标位置随机决定。

## 验证与排错

**验证**：在一个群里把「群聊频率」调到 `0.2` 保存，观察半小时，麦麦主动发言应明显减少；调回 `1` 后恢复正常。

- **规则不生效** — 确认规则所在的规则组就是当前启用的组，且规则本身没有被关闭。
- **配置保存时报错** — 检查规则组名是否为空、有无首尾空白或重名；群聊规则是否漏了平台或群号。
- **麦麦太吵或太安静** — 先调「群聊频率」，再考虑用动态发言规则组按群细分；防抖档位影响的是等待时间，不改变发言频率。
- **私聊完全不回** — 检查「暂停私聊回复」是否打开，以及是否有命中该用户的暂停规则。
