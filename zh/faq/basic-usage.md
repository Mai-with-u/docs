# 基础使用

## MaiBot 需要付费吗？

MaiBot 本身是开源软件，不收取软件使用费。实际运行通常需要调用大语言模型、视觉模型或 embedding 服务，是否收费及价格由对应服务商决定。

使用量主要受聊天频率、上下文长度、启用的功能和模型价格影响。可以通过降低发言频率、选择适合的模型和关闭暂时不用的功能控制开销。

## 应该选择什么模型？

没有适合所有人的固定答案。选择时重点确认：

- Planner 是否具备可靠的推理和工具调用能力。
- Replyer 的语言质量是否符合预期。
- 视觉任务使用的模型是否支持图片输入。
- 长期记忆使用的是否为 embedding 模型。
- API 服务的价格、延迟、稳定性和地区可用性。

具体角色和配置方式见[模型配置](../manual/configuration/model-config.md)。不建议只依据一份容易过时的型号推荐表选择模型。

## 一个 MaiBot 可以服务多个群聊吗？

可以。**能接入哪些群聊和私聊由 MaiBot 主程序的适配器策略统一决定**，适配器插件本身不再带内置名单，默认全部放行。策略有两个入口：

- **WebUI** — 侧边栏「配置管理」→ **适配器设置**（`/adapter-management`）：页面顶部「全局默认规则」卡片设置群聊 / 私聊的默认动作，选中某个适配器后在「黑白名单规则」页签里填要接收或屏蔽的群号 / 用户 ID，改完自动保存；
- **配置文件** — `config/adapter_policy.toml`：`[defaults.group]` / `[defaults.private]` 写兜底规则，`[[adapters]]` 条目按适配器实例写 `allow_ids` / `deny_ids`。

具体见[适配器管理](../manual/webui/adapter-management.md)。

## MaiBot 支持哪些平台？

平台支持由已安装的适配器决定。QQ 有两条路线：

- **本地客户端登录** — 装**统一 QQ 连接器**（插件名 `MaiBot-SnowLuma-Adapter`），用你自己的 QQ 号登录，一个插件同时支持 SnowLuma 与 NapCat 两类客户端；
- **开放平台机器人** — 装 **QQ 官方机器人**适配器，去 QQ 开放平台申请 AppID + AppSecret，不需要登录 QQ 客户端。

此外还有邮件、QQ 语音通话、iMessage 等社区适配器。1.3.0 起原独立的 SnowLuma 适配器与 NapCat 适配器已合并为统一 QQ 连接器，独立 NapCat 适配器已归档，实际可用能力以对应适配器版本为准。选型与安装见[接入平台](../manual/adapters/index.md)。

## 第一次使用需要注意什么？

建议先完成最小配置并验证消息链路，再逐步开启长期记忆、插件和其他高级功能。遇到异常时优先查看日志，同时记录 MaiBot、适配器和一键包版本，避免一次修改多个无关配置。

## 提问时需要提供什么？

请至少提供操作系统、MaiBot 版本、部署方式、适配器版本、完整错误日志、相关配置和复现步骤。公开日志或配置前应删除 API Key、访问令牌、Cookie 等敏感信息。

提问前的完整自查清单和 Issue 信息模板见[获取帮助](./getting-help.md)。
