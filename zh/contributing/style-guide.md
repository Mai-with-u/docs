# 文档风格指南

这一站的目标只有一句：**读者带着问题来，一屏之内拿到能直接用的答案。** 本站的行文与版面照搬 [DeepSeek API 文档](https://api-docs.deepseek.com/zh-cn/)：开头一句话说清能力，接着就是可直接复制的配置或命令，参数用定义列表，长内容折进 `::: details`，收尾只放验证与排错。

语法层写法（code-group、图标、Linkcard、容器、禁止表格）见[文档编写特性](./markdown-features)。

## 页面骨架

1. **H1 只写名字本身** — 不带序号、破折号、方括号代码段名。补充信息放正文或代码组标签，保证「本页目录」干净可扫读。
2. **一句话导语** — 1~2 句，说清「这个功能让你能做到什么」。导语后立刻给出最关键的信息：一条命令、一段配置、或一张能力清单。
3. **H2 按任务切** — 一个 H2 解决一件事，不要按「介绍 / 参数 / 注意事项」这类模板切块。
4. **参数用定义列表** — 每条写成「名字 — 默认值 / 取值 / 作用」，整段配置仍用可复制的代码块。
5. **长内容折叠** — 完整示例、边缘场景、推导过程收进 `::: details`。
6. **收尾只放验证与排错** — 教程与指南类给一个可执行的验证动作，加 2~5 个常见失败场景。参考类、索引页、FAQ、法律与元信息页不需要硬凑。

页面类型与骨架：

**教程**（第一次做这件事）— 目标 → 前置条件 → 编号步骤 → 验证
**指南**（做一件具体的事）— 直接结论 → 步骤或选项 → 排错
**参考**（查参数）— 定义列表逐字段：名称 — 默认值，作用
**概念**（理解原理）— 类比 → 图示 → 术语表

## 措辞

- 称呼「你」，不用「用户」「各位」。
- 命令直接给：「运行 `pnpm docs:build`」「把 `host` 改成 `0.0.0.0`」，不写「请考虑」「建议您可以」。
- 一句话说清一件事。能删的形容词全删。
- 不用感叹号、表情符号、「非常简单」「轻松」「一键搞定」这类营销词。
- 技术名词保持英文（API、Token、Hook、Plugin、WebUI、Adapter、Prompt、JSON、TOML），不硬翻成中文，也不加引号。
- 专有名词首次出现给一句解释，第二次之后不再解释。
- 警告写在它真正生效的位置，不堆在页首。

## 明确禁止

1. **复述界面上肉眼可见的操作** — 「点击右上角按钮，弹出窗口后选第一项」不写。只写读者看不到的：默认值、后果、前置条件。
2. **版本变更注记** — 不写「1.4.0 起支持」「旧版本没有」「相比上个版本新增」。直接介绍当前版本的事实。
3. **「不是 A，而是 B」/「A，不是非 A」** — 没有信息量的转折一律删。
4. **空泛指令** — 「根据实际情况设置」「按需配置」不写。要么给具体值，要么说明取值依据。

## 配置展示：整段模板 + 行尾注释

配置类内容给出**完整配置模板**，字段写全、注释写清，读者复制后只改标注处：

- **完整可复制** — 含所有节、所有字段，省略字段等于用默认值
- **注释讲三件事** — 字段作用、默认值、约束（如「必须大于 0」「与 NapCat 设置一致」）
- 单个易错字段可以在模板后补一条定义列表展开，整段配置一律用代码块
- 遵循[文档编写特性](./markdown-features)的 code-group 写法，标签带 `~vscode-icons:file-type-toml~`

## 侧边栏规则

侧边栏与页面同一套标准：读者要能**扫一眼就找到对的那条**。

- **分组** — 同级条目 ≥5 个且能按读者心智归类时分组。分组名说清区分维度，如 QQ 按接入路线分「本地客户端登录」「开放平台机器人」；不用「其他」「杂项」这类兜底名
- **条目命名** — `名称 — 差异化描述`：描述讲「是什么、适合谁、特色」，不讲「XX 的文档」。名字本身能区分时不必加描述
- **概览条目** — 每节第一项放概览页，命名「X 概览」（en: X Overview）
- **镜像对称** — zh/en 分组、条目、顺序一一对应，zh 为权威
- **正向措辞** — 写「官方推荐」，不写「可用（测试中）」

## 风格锚点

- 版面与节奏：**DeepSeek API 文档**（api-docs.deepseek.com/zh-cn）
- 结构分类：**Diátaxis**（diataxis.fr）— 教程 / 指南 / 参考 / 概念
- 语气：**Stripe 文档**与 **Google 开发者文档风格指南**的 Voice & Tone 章节
