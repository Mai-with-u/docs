# 更新日志

::: timeline 2026-08-18
- [1.2.0] Maisaka：优化 Replyer 回复多样性，根据情景使用不同回复模式；优化 Replyer 组织结构
- 回复效果评估标准升级（当前 v6）：回应度不再考虑用户回应速度，移除缺少明确语义的原始总分，无关联信息标记"已完成 / 无信息"，未走完观察窗口标记"不完整"不参与评分；评分分布改为逐条样本散点图；支持删除 / 清空评分记录
- 模型：正式支持 Response 端点；模型上下文与输出升级为扁平 Item-first 结构，独立保留正文、推理、函数调用、工具结果与 Provider 原生活动
- 表达方式：修复表达向量索引损坏后反复异常重启的问题，优化索引在线维护（增量分配、k-means++、无压缩原子写盘）
- 适配器：平台账号持久化为适配器实际报告的身份，同一实例多账号稳定识别为自身；支持适配器自动获取 ID；访问策略新增相互独立的群聊与私聊默认动作（默认放行，可改默认拒绝）
- WebUI [1.7.0]：新增独立的适配器管理与统一命令管理页面；优化模型配置布局；修复本地模型无法测试的 bug；设置页新增适配器已发现账号列表与在线状态、软禁用 / 恢复；允许按模式设置群聊频率（支持通配与默认配置）；推理过程日志新增输入、输出和总 Token 展示
- 消息：支持查看嵌套转发消息
- 插件 SDK：`send.text`、`send.emoji`、`send.image`、`send.forward`、`send.hybrid`、`send.command`、`send.custom` 支持 `return_details=True` 获取平台确认的最终消息 ID
- 优化启动引导
:::
